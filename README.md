# Film Festival Circuit Visualization Tool

The FFC visualization tool is a web-based, interactive, highly filterable force-directed node graph intended to visualize the film festival circuit.

Available at: https://ffc.herger.dev

## Built using

- React (Javascript)
- D3.js
- Vite

## Run Locally
```
git clone https://github.com/AdamHerger/ffcvisualization.git
```
```
npm install
```
```
npm run dev
```
